## طريقة الاختبار المعياري (A/B Testing):
1. لكل مجلد `Qxx`: أعطِ النموذج صور `question_*.png` فقط مع الطلب المناسب. **لا ترفق أبداً ملف التصحيح.**
2. أجرِ التجربة مرتين في نافذتي محادثة منفصلتين كلياً:
   - **الشرط أ (بدون Skill):** استعمل نص `PROMPT_A_BASELINE.txt`.
   - **الشرط ب (مع Skill):** استعمل نص `PROMPT_B_SKILL.txt`.
3. صحّح كلتا الإجابتين بمقارنتهما مع `ANSWER_KEY_official_corrige.pdf` وسلم التنقيط فيه، وسجّل العلامتين في `scoring_sheet.csv`.
4. قارن متوسط العلامات: إن لم يتحسن أداء النموذج بوضوح (زيادة ملموسة في العلامة أو اختفاء الأخطاء المنهجية)، فالـ Skill لا تضيف قيمة حقيقية.
