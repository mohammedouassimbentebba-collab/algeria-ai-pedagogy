# القاموس البيداغوجي والمصطلحي الوطني الموحد (Official Algerian Pedagogical Glossary)

يعد هذا القاموس المرجع الإلزامي الصارم لجميع نماذج ووكلاء الذكاء الاصطناعي (`AI Agents`) عند التعامل مع أسئلة واختبارات المناهج الجزائرية في التعليم الثانوي (شهادة البكالوريا) والجامعي (LMD).
**القاعدة الذهبية:** يُمنع منعاً باتاً استخدام أي مصطلح مشرقي أو أنجلوساكسوني أو بديل غير معتمد في وثائق وزارة التربية الوطنية والمفتشية العامة للبيداغوجيا والديوان الوطني للامتحانات والمسابقات (ONEC).

---

## 1. جدول المصطلحات الملزمة والبدائل الممنوعة عبر المواد

| المادة | المصطلح الجزائري الرسمي المعتمد (إلزامي 100%) | المصطلح المشرقي / الأجنبي غير المعتمد (ممنوع منعاً باتاً) | سياق الاستخدام وشبكة التقييم الوزارية (ONEC) |
|---|---|---|---|
| **الرياضيات** | **مبرهنة القيم المتوسطة (م.ق.م)** | نظرية القيمة الوسطى / الوسطية | إثبات وجود حلول للمعادلة $f(x) = 0$ على مجال $[\alpha, \beta]$ مع شروط الاستمرارية والرتابة التامة. |
| **الرياضيات** | **البرهان بالتراجع** | الاستقراء الرياضي | المراحل الثلاث الإلزامية: الخاصية $P(n)$، التحقق (الخطوة الابتدائية)، الوراثة، والخلاصة. |
| **الرياضيات** | **المستقيم المقارب المائل / العمودي / الأفقي** | خط التقارب المائل / الرأسي / الأفقي | التفسير الهندسي للنهايات عند أطراف مجالات التعريف. |
| **الرياضيات** | **جدول التغيرات** | جدول إشارة الدالة / مخطط السلوك | جدول معياري بـ 3 أسطر: $x$ والقيم الممنوعة (//)، إشارة $f'(x)$، وأسهم تغيرات $f(x)$. |
| **الرياضيات** | **نقطة الانعطاف** | نقطة الانقلاب | المشتقة الثانية تنعدم وتغير إشارتها أو الأولى تنعدم ولا تغير إشارتها أو المماس يخترق المنحنى. |
| **الرياضيات** | **القسمة الإقليدية والموافقات في $\mathbb{Z}$** | خوارزمية القسمة وباقي القسمة | حصري لشعبة رياضيات وتقني رياضي (الترديد $n$، الدوريات، وخوارزمية إقليدس لـ PGCD). |
| **الرياضيات** | **الاحتمالات المتساوية والشجرة التركيبية** | فضاء العينة المتجانس | حساب الاحتمالات، المتغير العشوائي وقانونه والأمل الرياضي $E(X)$ والتباين $V(X)$. |
| **العلوم الطبيعية** | **المسعى العلمي (Demarche Scientifique)** | الطريقة الاستقرائية / الاستنتاجية المجردة | الإطار المنهجي المهيكل لتمارين البكالوريا الثلاثة (مهمة بسيطة، استدلال علمي، ومسعى علمي كامل). |
| **العلوم الطبيعية** | **استغلال الوثائق** | قراءة المعطيات / شرح الصور | بروتوكول صارم: (1) التعريف بالوثيقة، (2) التحليل بمؤشرات دلالية (حيث نلاحظ...)، (3) الاستنتاج الدقيق. |
| **العلوم الطبيعية** | **التركيب / الربط (Synthèse)** | الملخص النهائي / الخلاصة السريعة | الإجابة التركيبية الصريحة عن المشكلة العلمية المطروحة في مقدمة التمرين بناءً على الاستنتاجات. |
| **العلوم الطبيعية** | **المهمة المركبة (Tâche Complexe)** | السؤال المركب / متعدد الفروع | تتطلب من الطالب تعبئة وتجنيد موارد متعددة والربط المنطقي بين عدة وثائق دون تجزئة السؤال. |
| **العلوم الطبيعية** | **النص العلمي المهيكل** | المقال العلمي / الإنشاء العلمي | هيكل إلزامي ثلاثي: مقدمة تطرح مشكلة علمية منتهية بعلامة استفهام، عرض منطقي بأفكار علمية دقيقة، وخاتمة كحل موجز. |
| **العلوم الطبيعية** | **الرسم التخطيطي الوظيفي / التحصيلي** | المخطط الإيضاحي / الرسم البياني | رسم علمي دقيق بقلم الرصاص، بيانات كاملة بأسهم مسطرة، إطار، وعنوان وظيفي دقيق في الأسفل. |
| **الفيزياء والكيمياء** | **مقاربة الأفعال المتبادلة وقوانين نيوتن** | قوانين الحركة لنيوتن (صيغ مشرقية) | تحديد المرجع العطالي المناسب، الجملة الميكانيكية المدروسة، جرد القوى الخارجية، وتطبيق القانون الثاني لنيوتن $\sum \vec{F}_{ext} = m\vec{a}$. |
| **الفيزياء والكيمياء** | **المعادلة التفاضلية** | معادلة الحركة الخطية | كتابة المعادلة التفاضلية بدلالة المتغير المطلوب بدقة ($v(t)$, $q(t)$, $u_c(t)$, $i(t)$) والتحقق من حلها وأبعاد ثوابتها بالتحليل البعدي. |
| **الفيزياء والكيمياء** | **التحليل البعدي (Analyse Dimensionnelle)** | حساب الوحدات الفيزيائية | إثبات تجانس الوحدات وتحديد أبعاد الثوابت (مثل ثابت الزمن $\tau = RC$ وثابت الجاذبية $G$). |
| **الفيزياء والكيمياء** | **جدول التقدم (Tableau d'avancement)** | جدول الحساب الكيميائي / جدول التفاعل | جدول قياسي بحالاته الثلاث: الابتدائية ($x=0$)، الانتقالية ($x(t)$)، والنهائية أو الأعظمية ($x_f$ / $x_{max}$). |
| **الفيزياء والكيمياء** | **التقدم الأعظمي $x_{max}$ والتقدم النهائي $x_f$** | المادة المحددة / الناتج النهائي | التمييز الدقيق بين التفاعل التام ($x_f = x_{max}$) وغير التام وحساب نسبة التقدم النهائي $\tau_f = \frac{x_f}{x_{max}}$. |
| **اللغة العربية** | **البناء الفكري** | فهم المقروء / الفهم والاستيعاب | دراسة المضمون، الفكرة العامة، الأفكار الجزئية، الحقل الدلالي، النمط ومؤشراته، ونوع النص وظواهره (الالتزام، الرمز). |
| **اللغة العربية** | **البناء اللغوي** | القواعد والأساليب / التراكيب | الإعراب اللفظي والتقديري، إعراب الجمل (لها محل / لا محل لها)، الصور البيانية وشرحها وبلاغتها، والمحسنات البديعية. |
| **اللغة العربية** | **التقويم النقدي** | النقد الأدبي / دراسة النصوص | خاص بالشعب الأدبية: المدارس الأدبية (الرابطة القلمية، مدرسة الإحياء والبعث)، شعر التفعيلة، وظاهرة الحزن والألم، الالتزام. |
| **اللغة العربية** | **الاتساق والانسجام** | التماسك والترابط النصي | استخراج الروابط اللغوية والمنطقية: حروف العطف، أسماء الإشارة والموصول، الضمائر وعائدها، والتكرار والحقول الدلالية. |
| **الفلسفة** | **الطريقة الجدلية** | المقال الجدلي / الحوار الفلسفي | هيكل إلزامي: طرح المشكلة (تمهيد، مسار، عناد فلسفي، طرح السؤال)، محاولة حل المشكلة (عرض الأطروحة وحججها ونقدها، عرض نقيض الأطروحة وحججها ونقدها، التركيب أو التجاوز)، حل المشكلة (استنتاج منسجم). |
| **الفلسفة** | **طريقة الاستقصاء بالوضع** | إثبات صحة الأطروحة | الدفاع عن أطروحة تبدو غير صحيحة: طرح المشكلة (فكرة شائعة، نقيضها، وضبط المشكلة بصيغة الدفاع)، محاولة حل المشكلة (عرض منطق الأطروحة، الدفاع بحجج شخصية ومذاهب، نقد خصوم الأطروحة)، حل المشكلة (التأكيد على مشروعية الدفاع). |
| **الفلسفة** | **طريقة المقارنة** | المقارنة بين مفهومين | طرح المشكلة (الحذر من المظاهر، التساؤل)، محاولة حل المشكلة (أوجه الاختلاف، أوجه الاتفاق، أوجه التداخل)، حل المشكلة (نسبة الترابط والتكامل). |
| **الفلسفة** | **تحليل نص فلسفي** | شرح النص | تحديد المشكلة، تحديد موقع النص، منطق صاحب النص وحججه، والمناقشة والتقييم، وحل المشكلة. |
| **اللغات الأجنبية** | **Le Compte-rendu critique / objectif** | الملخص / Synthesis / Summary | تقنية رسمية جزائرية حصرية لتلخيص النصوص التاريخية والحجاجية (Amorce, Résumé des idées, Critique pour les littéraires). |
| **التاريخ والجغرافيا** | **السندات والخرائط والمصطلحات** | الوثائق الإضافية / الرسوم | شرح المصطلحات وفق سياقها الزماني والمكاني والسياسي المعتمد في دليل الأستاذ الوزاري وتحديد الدول على الخرائط الصماء. |
| **العلوم الإسلامية** | **الأحكام والفوائد** | الدروس المستفادة / العبر | استخراج دقيق وفق الضوابط الشرعية المبرمجة: الأحكام تبدأ بـ (وجوب، تحريم، استحباب، كراهة، جواز)، والفوائد جمل اسمية مفيدة. |
| **تسيير محاسبي ومالي** | **النظام المحاسبي المالي (SCF)** | المعايير المحاسبية العامة / GAAP | المرجع المحاسبي الوطني الصارم لجميع قيود اليومية، التثبيتات، والمخزونات وفق مدونة الحسابات الرسمية. |
| **تسيير محاسبي ومالي** | **الميزانية الوظيفية ومؤشرات التوازن** | الميزانية العمومية التقليدية | حساب رأس المال العامل الصافي الإجمالي ($FRNG$)، احتياج رأس المال العامل ($BFR$)، والخزينة الصافية ($TN$). |
| **تسيير محاسبي ومالي** | **اهتلاك التثبيتات وخسائر القيمة** | استهلاك الأصول وإهلاك الديون | التمييز بين الاهتلاك الخطي، المتناقص، والمتزايد، وإعداد جدول الاهتلاك مع قيود التسوية في 31/12. |
| **اقتصاد ومناجمنت** | **الكتلة النقدية والتضخم والبطالة** | المعروض النقدي ومؤشرات السيولة | تعريفات وقوانين البنك المركزي الجزائري، أدوات السياسة النقدية، وآليات معالجة التضخم والبطالة. |
| **القانون** | **عقد العمل، الشركة التجارية، والالتزامات** | العقود العامة والقانون المدني | أحكام قانون العمل الجزائري (علاقات العمل الفردية والجماعية) والقانون التجاري (شركات الأشخاص والأموال). |
| **الهندسة الميكانيكية** | **دراسة التصميم والإنشاء والتحليل الوظيفي** | ميكانيكا الآلات العامة | دفتر الشروط، نظام السلسلة الحركية (SADT)، رسم التعاريف، مخططات التجميع، والتوافقات (Ajustements). |
| **الهندسة الكهربائية** | **الأنظمة الآلية والمنطق التعاقبي (GRAFCET)** | الدوائر المنطقية العامة | المخطط الوظيفي للتحكم في المراحل والانتقالات (GRAFCET)، العدادات والسجلات والمؤقتات، ومكبرات العمليات. |
| **الهندسة المدنية** | **مقاومة المواد (RDM) وحساب الجوائز والشدات** | هندسة الإنشاءات العامة | حساب ردود الأفعال، عزم الانحناء $M_f(x)$، الجهد القاطع $T(x)$، والتسليح وفق المعايير الجزائرية (CBA 93). |
| **هندسة الطرائق** | **الكيمياء العضوية الحركية وهندسة التفاعلات** | الصناعات الكيميائية | دراسة تفاعلات الإضافة والاستبدال للأحماض الأمينية والليبيدات والبوليميرات، وتوازن التفاعلات الصناعية. |

## 2. الرموز والاختصارات الوطنية المعتمدة

- **م.ق.م:** مبرهنة القيم المتوسطة (Mathematics).
- **ق.ع.م (PGCD):** القاسم المشترك الأكبر (Mathematics).
- **م.ع.أ (PPCM):** المضاعف المشترك الأصغر (Mathematics).
- **ك.م:** كمية المادة (Physics & Chemistry).
- **م.ن:** المرجع النظري / المرجع العطالي (Physics).
- **ح.ع.ت:** حالة عدم التعيين (Mathematics Limits).
- **ONEC:** الديوان الوطني للامتحانات والمسابقات (Office National des Examens et Concours).
- **LMD:** ليسانس، ماستر، دكتوراه (نظام التعليم العالي الجزائري).

## 3. مؤشرات أفعال الأداء السلوكية في شبكات التصحيح (Action Verbs)

عندما يرد فعل أمر في أسئلة البكالوريا، يجب على الوكيل ترجمته إلى المستوى الإجرائي المطابق لتصحيح الوزارة:
1. **حلّل (Analyser):** تفكيك المعطيات أو المنحنى إلى أجزاء وتحديد الدلالة (في المجال $[a, b]$ نلاحظ تزايد... مما يدل على...).
2. **فسّر (Expliquer / Interpréter):** إعطاء الأسباب البيولوجية أو الفيزيائية العميقة للظاهرة المشاهدة (يعود ذلك إلى...).
3. **قارن (Comparer):** تحديد أوجه الشبه وأوجه الاختلاف للخروج باستنتاج تركيبي منسجم.
4. **استنتج (Déduire):** استخراج معلومة جديدة أو قانون مستتر مباشرة من الخطوة السابقة وليس من الحفظ المسبق.
5. **صادق على صحة الفرضية (Valider l'hypothèse):** ربط الاستنتاجات بالفرضية المقترحة والتصريح جلياً: "وهذا ما يؤكد صحة الفرضية رقم... وينفي صحة الفرضية رقم...".
